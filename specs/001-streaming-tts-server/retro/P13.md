## Requirements Summary

### Timeouts
- **FR-016**: System MUST implement configurable timeouts
  - Idle connection timeout (5 minutes default)
  - Synthesis timeout (30 seconds per sentence)
  - Session initialization timeout (10 seconds)

### Security
- **FR-014**: System SHOULD warn on startup if config file has overly permissive permissions (>0600)
- **FR-008**: System MUST implement reasonable size limits on text chunks (64KB max)

### Observability
- **NFR-005**: All WebSocket connections MUST be logged with session_id correlation
- **NFR-006**: HTTP responses SHOULD include X-Request-ID header for tracing
