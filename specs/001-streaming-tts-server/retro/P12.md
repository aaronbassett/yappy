## Implementation Summary

### OpenAI TTS Provider (`yappy-provider-openai`)

Full implementation with ~850 lines of code:

- **`OpenAiConfig`**: Configuration struct with API key, model, endpoint, and timeout
- **`OpenAiProvider`**: Implements `TtsProvider` trait
- **Voices**: 6 voices (alloy, echo, fable, onyx, nova, shimmer)
- **Formats**: Opus, MP3, PCM (native OpenAI output, no transcoding needed)
- **Features**:
  - Direct reqwest streaming from OpenAI API
  - Rate limiting with exponential backoff (max 3 retries)
  - Respects `Retry-After` header
  - Speed adjustment (0.25-4.0 range)
  - Cancellation support via `CancellationToken`
  - Text length validation (max 4096 chars)

### AVSpeech Provider (`yappy-provider-avspeech`)

Full implementation with ~950 lines of code (macOS only):

- **`AvSpeechConfig`**: Configuration struct with default voice
- **`AvSpeechProvider`**: Implements `TtsProvider` trait
- **Voices**: Dynamic system voice enumeration via `AVSpeechSynthesisVoice.speechVoices()`
- **Formats**: PCM only (server handles transcoding)
- **Features**:
  - Uses `writeUtterance:toBufferCallback:` for streaming (FR-031)
  - Voice gender mapping to `VoiceGender` enum
  - Speech rate, pitch, and volume support
  - Cancellation support
  - Platform-gated with `#[cfg(target_os = "macos")]`

## Decisions Made

1. **OpenAI native formats**: OpenAI TTS API natively outputs Opus/MP3/PCM, so no server-side transcoding is needed. This is more efficient than transcoding.

2. **AVSpeech PCM output**: AVSpeech outputs PCM buffers, which the server transcodes to the requested format. This is consistent with how Kokoro works.

3. **objc2 bindings**: Used objc2-avf-audio (v0.3.2) for safe Rust-Objective-C interop on macOS instead of raw FFI.

4. **Rate limit strategy**: Exponential backoff with max 3 retries and 30s cap. Respects `Retry-After` header when present.

5. **API key from environment**: OpenAI provider supports both config file API key and `OPENAI_API_KEY` environment variable.

## Learnings

1. **objc2 bindings are comprehensive**: The objc2 ecosystem provides type-safe bindings to Apple frameworks, making macOS integration much safer than raw FFI.

2. **OpenAI streaming response**: OpenAI returns the complete audio file as a streaming HTTP response, not discrete chunks. We buffer and chunk it for our WebSocket protocol.

3. **Feature-gated compilation**: Using `#[cfg(target_os = "macos")]` at the crate level keeps the crate empty on non-macOS platforms, which compiles cleanly everywhere.

4. **Provider registration pattern**: The pattern of feature-gated `register_*_provider()` functions works well for conditional provider initialization.
